Virtual Models

A virtual model is an alias (e.g. coding-fast) that maps to one or more {provider, model} candidates. The gateway auto-selects the best candidate via the routing strategy and fails over across candidates of the SAME virtual model. Clients send the virtual id — no provider/model knowledge required.
